# Aurora 1.5.1

## Fixes
- **No more lag when picking up star shards.** Collecting a shard or relic used to freeze the game for a moment, which was worst on Level Impossible. It's now smooth.
- **The Windows download runs from anywhere.** **Aurora.exe** is now one self-contained file, so you can put it on your desktop and double-click it. You can also use **Aurora-Setup.exe**, which installs the game with an **Aurora** desktop and Start menu shortcut.
- **Relics only count when you finish the level.** Grabbing a relic and quitting no longer saves it. Reach the portal to keep it.

## New
- **Clicky menu sounds.** Menus, settings and the in-game overlays now use crisp, satisfying clicks everywhere. The old musical notes are still available: go to **Settings → Audio → Menu Sound Style** and pick **Chimes**. **Clicks** is the default and recommended.

## Download
- **Aurora.exe** is portable: put it anywhere and run it.
- **Aurora-Setup.exe** installs the game and adds a desktop shortcut.

If Windows SmartScreen appears, click **More info → Run anyway**.
