# Aurora 1.6.2

## Changes
- **One download.** Each release now has a single file: **Aurora-Setup.exe**.
- **Updates install over your old version.** Run the new Aurora-Setup.exe and it replaces the version you have, keeping your progress, relics and settings. It then starts the game. You don't need to uninstall first or pick a folder.

> If you used the portable Aurora.exe from 1.5.1–1.6.1, you can delete it after installing.
